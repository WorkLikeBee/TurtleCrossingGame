# TurtleCrossingGame
CrossyRoad demo with Python

🎮 Gameplay
Use the Up Arrow key to move the turtle forward.
Avoid the cars moving across the screen.
Each time you reach the top:
Your level increases 📈
Car speed increases 🚗💨
If you collide with a car → Game Over

|How It Works
|-  -main.py
|     +Sets up the screen
|      +Handles game loop and user input
|      +Detects collisions and level progression
|-  -player.py
|        +Controls turtle movement
|        +Detects when the player reaches the finish line
|        + Resets player position
|-  -car_manager.py
|          + Generates cars at random positions
|          + Moves cars across the screen
|          + Increases speed as levels progress
|-  -scoreboard.py
          + Displays current level
          +Shows “Game Over” message
